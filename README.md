### Simple To Do App
- 간단한 텍스트 형태의 투두를 추가할 수 있다.
- 삭제 버튼으로 투두를 삭제할 수 있다.
- 모든 투두는 카테고리에 포함되며, 카테고리를 변경할 수 있다.
- 특정 카테고리에 속한 투두만 모아서 볼 수 있으며, 선택된 카테고리탭이 없을 경우 전체 투두를 볼 수 있다.
- 특정 카테고리탭이 선택된 상태에서 투두를 추가 시, 해당 투두는 자동으로 현재 카테고리에 포함된다.
- 카테고리와 투두리스트는 로컬스토리지에 저장된다.
- 라이트모드와 다크모드를 선택할 수 있다.
